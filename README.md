
# Adaxes User Provisioning

## Overview

This repository documents user account provisioning and administration using Adaxes and Microsoft Active Directory.

It covers common account management tasks, onboarding workflows and basic troubleshooting.

## User Account Management

Common tasks include:

- Creating new user accounts
- Updating user information
- Enabling and disabling accounts
- Resetting passwords
- Unlocking user accounts
- Reviewing Organizational Units (OUs)
- Managing security group memberships

## User Onboarding

A typical onboarding process includes:

1. Receive an approved account creation request.
2. Verify the required user details.
3. Open the Adaxes web interface.
4. Select the appropriate user creation workflow.
5. Enter the required account information.
6. Review the OU and security group assignments.
7. Submit the request.
8. Verify that the account was created successfully.

## User Offboarding

Common offboarding activities include:

- Disabling the user account
- Reviewing group memberships
- Removing access according to approved procedures
- Updating the related service request
- Following account retention policies

## Adaxes Automation

Adaxes supports administrative automation through:

- Business rules
- Scheduled tasks
- Approval workflows
- Custom commands
- User provisioning templates

Available features depend on the organization's configuration.

## Basic Troubleshooting

| Issue | What to Check |
|---|---|
| User creation fails | Required fields and permissions |
| Account not found | Domain, OU and search filters |
| Missing application access | Group membership and access requirements |
| Workflow pending | Approval status |
| Account locked | Account status and lockout information |

## Security

- Follow approved access management procedures.
- Apply least-privilege principles.
- Verify user identity before password resets.
- Never publish real user information or credentials.

## Note

This repository contains general technical documentation. It does not include internal company configurations or sensitive information.
